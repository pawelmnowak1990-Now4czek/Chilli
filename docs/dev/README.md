# Build log

These notes were written step by step while Chilli was being built, from the first database table
to the open-source preparation and the first public release (00 to 28, plus `wdrozenie.md`, the first server deployment). They are
kept for history and for anyone curious about why things are the way they are. Most of the earlier
notes are in Polish and describe one specific server and setup; for installing and using Chilli,
see the [README](../../README.md) and [docs/guides/](../guides/).
