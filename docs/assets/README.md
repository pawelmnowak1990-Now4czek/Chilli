# Assets

Images used by the README and the guides.

- `demo.gif`: the animated story at the top of the README (a screenshot with the Action Button, a link
  from the share sheet, the server describing the save, then an AI client finding it weeks later).
  It is an illustration, not a screen recording; the source and the rebuild steps are in `demo/`.
- `demo.mp4`: the same animation as a video (1600x900), for sharing.
- `logo.svg` and `logo.png` (512x512): the Chilli logo, a smiling chili pepper on a cream rounded square.
  Drawn from scratch for this project, MIT like the rest of the repository.
- `social-preview.png` (1280x640): the image GitHub shows when the repository link is shared
  (Settings, General, Social preview). Its source is `brand/social-preview.html`; to rebuild it, open
  the page in a 1280x640 browser window and take a screenshot.
